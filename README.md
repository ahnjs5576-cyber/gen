# 하루 수리통계 θ̂

수리통계학의 핵심을 **하루 5분씩** 익히는 웹 앱입니다. 서버나 설치 없이 HTML 파일 하나로 돌아갑니다.

## 무엇을 하나

- **32일 커리큘럼 (7개 단원)**: 확률의 언어 → 확률변수 → 주요 분포 → 여러 확률변수 → 표본분포와 극한정리 → 추정 → 가설검정
- **레슨 하나의 구성**: 한 줄 직관 → 핵심 아이디어 → 외워 둘 공식 → 예제(풀이 접기) → 자주 하는 실수 → 확인 퀴즈 3문항(해설 포함) → 오늘의 한 줄
- **직접 만져 보는 시뮬레이션**: 이항분포 탐색기(Day 8), 큰 수의 법칙 동전 던지기(Day 19), 중심극한정리 표본평균 히스토그램(Day 20)
- **간격 반복 복습**: 레슨을 끝내면 핵심 공식 카드 2장이 저장되고 1 → 3 → 7 → 14 → 30 → 60일 간격으로 다시 나옵니다. 헷갈리면 다음 날로 돌아갑니다.
- **매일 흐름**: '오늘' 화면이 다음 레슨을 하나 골라 주고, 연속 학습일과 최근 2주 기록, 단원별 진도를 보여 줍니다.

진도는 브라우저의 `localStorage`에만 저장됩니다(계정·서버 없음).

## 쓰는 법

- 그냥 `index.html`을 브라우저로 열면 됩니다.
- GitHub Pages: 저장소 Settings → Pages → Branch를 이 브랜치의 루트(`/`)로 지정하면 바로 배포됩니다.

## 구조

```
src/
  content/part1.js   Unit 1–4 레슨 데이터 (Day 1–17)
  content/part2.js   Unit 5–7 레슨 데이터 (Day 18–32)
  app.js             화면, 퀴즈, 복습 스케줄, 시뮬레이션 위젯
  styles.css         디자인 (라이트/다크)
  head.html, body.html
scripts/
  build.mjs          src/를 합쳐 index.html(단일 파일)과 dist/artifact.html 생성
  check-content.mjs  레슨 데이터 점검 (선택지 수, 수식 $ 짝, 백슬래시 누락)
```

수식은 MathJax 3(SVG 출력)으로 그립니다.

## 레슨 추가·수정

1. `src/content/part*.js`에서 레슨 객체를 고치거나 추가합니다.
   - 수식은 `$...$`(인라인), `$$...$$`(블록). 문자열은 ``r`...` ``(String.raw)로 감싸 백슬래시를 그대로 둡니다.
   - `quiz[].choices[0]`이 정답입니다. 화면에서는 섞여서 나옵니다.
2. `npm run check`로 데이터를 점검하고 `npm run build`로 `index.html`을 다시 만듭니다.
