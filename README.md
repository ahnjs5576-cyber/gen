# 파이썬 한 입

하루 5~8분, 핵심만 골라 배우는 **30일 파이썬 코스** 웹앱입니다.
설치 없이 브라우저에서 바로 코드를 고치고 실행할 수 있어요.

## 하루 한 레슨의 흐름

1. **오늘의 핵심 3줄**: 꼭 기억할 내용만 형광펜으로 표시
2. **직접 실행해 보기**: 예제 코드를 고쳐서 ▶ 실행
3. **확인 퀴즈**: 4지선다 한 문제
4. **실습**: 직접 코드를 쓰고 `채점하기`로 자동 채점 (힌트 / 정답 보기 제공)
5. **완료 도장**: 진도표에 도장이 찍히고 연속 학습일이 늘어나요

- 기본값으로 레슨을 마친 **다음 날** 새 레슨이 열려요(설정에서 끌 수 있음).
- 홈 화면의 **복습 한 입**은 이미 마친 레슨의 퀴즈를 하나씩 다시 내 줘요.
- 진도와 작성한 코드는 브라우저 `localStorage`에 저장돼요.

## 커리큘럼

| 주차 | 내용 |
| --- | --- |
| 1주차 · 기초 문법 | print, 변수, 숫자 계산, 문자열, f-string, input과 형변환, 참·거짓 |
| 2주차 · 흐름과 리스트 | if, 리스트, 리스트 다루기, for, while, 합계·최댓값 패턴, 문자열 메서드 |
| 3주차 · 자료구조와 함수 | 딕셔너리, 튜플·집합, 함수, 매개변수, 중첩 반복, 리스트 컴프리헨션, 예외 처리 |
| 4주차 · 도구와 객체 | 모듈, 내장 함수, 정렬 key와 lambda, 클래스, 메서드, 상속, 중첩 자료구조, 미니 프로젝트 2개 |

## 실행 방법

정적 파일만으로 동작해요. 빌드 과정이 없어요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages(Settings → Pages → 브랜치 선택)에 올리면 바로 서비스할 수 있어요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 뼈대 + 파이썬 실행기(Brython 위에서 도는 작은 러너) |
| `lessons.js` | 30일 레슨 데이터. 레슨을 추가·수정할 때는 이 파일만 고치면 돼요 |
| `app.js` | 화면 전환, 진도·연속 학습 계산, 코드 편집기, 퀴즈, 자동 채점 |
| `style.css` | 디자인 (라이트/다크 모드 지원) |

파이썬 코드는 [Brython](https://brython.info) 3.13.2(CDN)로 브라우저에서 실행돼요.
`input()`은 편집기 아래 '입력값' 칸의 내용을 한 줄씩 읽어요.
