# 자료구조 한 입

하루 5분, 핵심만. 18일 동안 자료구조를 하나씩 쉽게 배우는 웹 서비스예요.

## 하루 학습 흐름

레슨 하나는 약 5분이고, 짧은 카드를 넘기며 진행해요.

1. **핵심 한 줄**: 그 자료구조를 한 문장으로 정리하고, 일상의 비유를 들어요.
2. **꼭 기억할 포인트** 3~4개와 자주 하는 실수
3. **직접 해보기**: 버튼을 눌러 push/pop, 해시 충돌, BST 삽입, 힙 정렬, BFS/DFS 같은 동작을 눈으로 확인해요.
4. **연산과 시간 복잡도** 표 (빠름/로그/선형/제곱을 색으로 구분)
5. **Python 코드** 예제
6. **퀴즈 3문제**와 해설

## 매일 꾸준히 하도록 돕는 기능

- **오늘의 한 입**: 홈 화면에서 오늘 배울 레슨 하나만 추천해요. 하루치를 마치면 내일 배울 내용을 미리 보여 줘요. 원하면 하나 더 볼 수도 있어요.
- **연속 학습일**과 최근 7일 기록 (비트 `0`/`1`로 표시)
- **간격 반복 복습**: 틀린 문제는 1일 뒤, 맞히면 3일 뒤, 다시 맞히면 7일 뒤에 또 나와요. 세 번 연속 맞히면 목록에서 빠져요.
- **섞어서 5문제**: 이미 배운 레슨에서 무작위로 문제를 골라 풀어요.

학습 기록은 브라우저 `localStorage`(`dsbite.v1` 키)에만 저장돼요. 서버나 회원가입은 필요 없어요.

## 실행

빌드 과정이 없는 정적 사이트예요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

GitHub Pages에 그대로 올려도 동작해요. (Settings → Pages → 브랜치 선택)

## 구조

```
index.html        # 진입점
css/style.css     # 디자인 토큰(라이트/다크) + 컴포넌트 스타일
js/lessons.js     # 커리큘럼 데이터 (레슨 추가·수정은 여기만)
js/demos.js       # 레슨별 인터랙티브 데모
js/app.js         # 라우팅(#home, #map, #review, #day-N), 진도·연속일·복습 로직
```

### 레슨 추가하기

`js/lessons.js`의 배열에 객체 하나를 추가하면 돼요.

```js
{
  id: "skip-list",               // 고유 id (코드 파일 이름으로도 쓰임)
  title: "스킵 리스트", en: "Skip List",
  tagline: "핵심 한 줄",
  analogy: "비유",
  points: ["포인트 1", "포인트 2", "포인트 3"],
  pitfall: "자주 하는 실수 (선택)",
  demo: null,                    // js/demos.js 에 만든 데모 이름, 없으면 null
  ops: { head: ["연산", "시간", "메모"], rows: [["검색", "O(log n)", "평균"]] },
  code: `# Python 예제`,
  quiz: [{ q: "질문", options: ["A", "B", "C", "D"], answer: 0, why: "해설" }]
}
```

`ops.rows`에서 `O(`로 시작하는 칸은 자동으로 복잡도 색 배지가 돼요.
