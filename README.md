# 하루 CS

알고리즘 · 운영체제 · 데이터베이스시스템 · 컴퓨터구조 · 머신러닝 · 딥러닝을
**매일 5분씩, 핵심만 쉽게** 배우는 웹 앱입니다.

## 어떻게 공부하나요

| 화면 | 하는 일 |
| --- | --- |
| **오늘** | 고른 과목을 날마다 돌아가며 그날 배울 레슨을 정해 줍니다(기본 하루 2개). 다 끝내면 "한 개 더 배우기"로 이어서 볼 수 있어요. |
| **레슨** | 한 줄 요약 → 일상 비유 → 핵심 3~5개 → 예시(코드/계산) → 용어 → 흔한 오해 → 확인 퀴즈 2~3문항 |
| **복습** | 간격 반복. 배운 레슨이 1 → 3 → 7 → 14 → 30일 뒤에 퀴즈로 다시 나오고, 틀리면 1일부터 다시 시작합니다. |
| **과목** | 과목별 레슨 목록과 진도. 원하는 레슨을 바로 열 수 있어요. |
| **기록** | 연속 학습일, 최근 10주 학습 달력, 과목별 진도와 정답률 |
| **설정** | 배울 과목, 하루 레슨 수, 테마, 기기 간 기록 옮기기(백업 코드), 초기화 |

과목마다 16개 레슨, 모두 96개 레슨이 들어 있습니다. 학습 기록은 브라우저(localStorage)에만 저장되며 서버나 계정이 필요 없습니다.

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000   # 그다음 http://localhost:8000 열기
```

`index.html`을 파일로 바로 열어도 동작합니다(오프라인 캐시만 빠짐).

### 휴대폰에서 매일 쓰기

GitHub 저장소의 **Settings → Pages**에서 이 브랜치의 루트(`/`)를 배포하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.
휴대폰 브라우저에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있고, 한 번 연 뒤에는 오프라인에서도 동작합니다.

## 구조

```
index.html            앱 셸
styles.css            디자인 토큰과 화면 스타일 (라이트/다크)
app.js                오늘 계획, 퀴즈, 간격 반복, 기록, 설정
content/<과목>.js     과목별 레슨 데이터
sw.js                 오프라인 캐시
scripts/validate.mjs  콘텐츠 형식 검사
scripts/smoke.mjs     브라우저 스모크 테스트 (Playwright)
CONTENT_GUIDE.md      레슨 작성 규칙
```

## 레슨 추가·수정

`CONTENT_GUIDE.md`의 형식대로 `content/<과목>.js`의 `lessons` 배열에 항목을 추가한 뒤 검사합니다.

```bash
node scripts/validate.mjs   # 콘텐츠 형식 검사
node scripts/smoke.mjs      # 실제 브라우저로 주요 흐름 확인
```
