# 폰비서 — 말로 시키면 안드로이드 앱을 대신 조작하는 비서

> “카톡 엄마한테 10분 늦는다고 답장해”
> “유튜브에서 아이유 좋은 날 틀어 줘”
> “방금 온 카톡 뭐래?”

말로 지시하면 **Claude**가 휴대폰 화면을 읽고, 버튼을 누르고, 글자를 입력해서 실제 앱으로 일을 끝낸 뒤 결과를 소리로 알려 줍니다.
음성 인식(STT) 결과에 오타나 비슷한 발음 오류가 있어도(“카토게 답짱해”) 문맥으로 알아듣도록 만들었습니다.

---

## 어떻게 동작하나요

```
 말하기 ──► 음성 인식(ko-KR) ──► Claude (도구 사용 루프) ──► 결과를 TTS로 읽어 줌
                                   │  ▲
                 도구 호출(누르기 등) ▼  │ 바뀐 화면
                         ┌──────────────────────────────┐
                         │ 접근성 서비스: 화면 읽기·터치·입력 │
                         │ 알림 리스너: 카톡 알림 읽기·바로답장 │
                         │ 인텐트: 앱 열기·유튜브 검색·링크    │
                         └──────────────────────────────┘
```

| 하는 일 | 방법 |
| --- | --- |
| 카톡 답장 | 최근 카톡 알림이 있으면 알림의 **답장 기능**으로 앱을 열지 않고 바로 보냄. 알림이 없으면 카카오톡을 열어 채팅방을 찾아 입력·전송 |
| 유튜브 재생 | 유튜브 앱 검색 결과를 바로 열고, 지시에 맞는 영상을 눌러 재생 |
| 메시지 읽어 주기 | 받은 알림(카톡·문자 등)을 요약해서 소리로 읽어 줌 |
| 그 밖의 앱 조작 | 화면 요소 목록(+필요하면 번호가 표시된 스크린샷)을 보고 누르기·입력·스크롤·뒤로가기 등을 반복 |

**안전장치**
- 메시지 전송·전화·결제·삭제처럼 되돌리기 어려운 일은 보내기 직전에 **“OO에게 ‘…’라고 보낼까요?”** 하고 소리로 확인받습니다(설정에서 끌 수 있음). “응/네/보내”면 진행, “아니/취소”면 멈춤.
- 화면·알림에 보이는 글(받은 메시지, 웹페이지 등)은 지시로 따르지 않도록 했습니다. 남이 보낸 메시지에 “이 링크 눌러” 같은 말이 있어도 무시합니다.
- 비밀번호·인증번호·카드번호는 입력하지 않습니다.
- 작업 중에 떠 있는 버튼(주황색)을 누르면 즉시 멈춥니다.

## 설치 (휴대폰만으로)

1. **APK 받기** — 이 저장소의 **Releases → “폰비서 최신 APK” → `phonebutler.apk`** 를 휴대폰 브라우저로 내려받습니다.
   (Actions 탭의 “폰비서 APK 빌드” 실행 결과에서도 받을 수 있어요.)
2. **설치** — 파일을 열고, “출처를 알 수 없는 앱 설치”를 허용합니다.
3. **폰비서 앱 열기** → 화면의 순서대로:
   1. ① 마이크 권한 **허용**
   2. ② 접근성 **켜기** → “폰비서 (화면 대신 조작)” 켜기
      - 회색으로 막혀 있으면(Android 13 이상, 직접 설치한 앱의 제한): 폰비서 앱의 **[앱 정보 열기] → 오른쪽 위 ⋮ → ‘제한된 설정 허용’** 후 다시 켭니다.
   3. ③ 알림 접근 **켜기** → “폰비서 (알림 읽기·답장)” 허용
   4. ④ **Claude API 키** 입력 → 저장 → [연결 테스트]
      - 키는 <https://console.anthropic.com> → API Keys에서 만들 수 있습니다(사용량만큼 요금이 나갑니다).

## 쓰는 법

말을 거는 방법은 네 가지입니다.

| 방법 | 설명 |
| --- | --- |
| **떠 있는 마이크 버튼** | 접근성을 켜면 어느 앱 위에서나 화면 오른쪽에 동그란 버튼이 떠요. 누르면 듣기, 작업 중 누르면 중지, 끌어서 위치 이동, 길게 누르면 폰비서 앱 열기 |
| **빠른 설정 타일** | 상단바를 내려 ✏️(편집) → “폰비서에게 말하기” 타일 추가 |
| **접근성 버튼** | 설정 → 접근성에서 내비게이션 바 접근성 버튼을 폰비서에 지정 |
| **앱 안의 큰 마이크** | 글자로 시키기도 가능 |

일부 기기는 “기본 디지털 어시스턴트”(홈 길게 누르기)로도 부를 수 있습니다.

색깔: 파랑 = 대기, 빨강 = 듣는 중, 주황 = 처리 중/말하는 중.

### 설정

- **모델**: Claude Opus 5.5(기본, 가장 정확) / Sonnet 5.5(저렴) / Haiku 5.5(가장 빠르고 저렴)
- **생각 깊이**: 빠르게(기본) / 보통 / 꼼꼼하게 — 복잡한 앱 조작이 자꾸 실패하면 올려 보세요.
- **메시지 보내기 전에 소리로 확인받기** (기본 켜짐)
- **떠 있는 마이크 버튼**, **결과를 소리로 읽어 주기**

## 알아 둘 점 / 한계

- **개인정보**: 명령을 처리하는 동안 현재 화면의 글자(필요하면 스크린샷)와 관련 알림 내용이 Claude API(Anthropic)로 전송됩니다. 폰비서는 그 내용을 따로 저장하지 않으며, 알림은 메모리에만 잠깐 보관했다가 앱이 꺼지면 사라집니다. API 키는 이 앱만 읽을 수 있는 내부 저장소에 저장됩니다.
- **알림 바로답장**은 폰비서가 켜진 *뒤에* 온 알림에만 됩니다. 오래된 대화는 카카오톡을 열어서 처리합니다.
- **스크린샷**은 Android 11 이상에서만 됩니다(그 아래는 화면 글자 목록만 사용).
- 은행 앱 등 **보안 화면**은 읽거나 찍을 수 없습니다.
- 음성 인식은 기기의 기본 음성 인식(보통 Google)을 사용하며 인터넷이 필요할 수 있습니다.
- 앱 화면 구성이 바뀌면 조작이 틀릴 수 있습니다. 처리 과정은 폰비서 앱의 “진행 기록”에서 볼 수 있어요.
- 호출어(“헤이 폰비서”)로 항상 듣기는 아직 없습니다(배터리·개인정보 문제로 버튼 방식만).

## 개발자용

### 구조

```
app/src/main/java/kr/phonebutler/
├── agent/
│   ├── AgentLoop.kt        Claude Messages API 도구 사용 루프 (안드로이드 비의존, 테스트 대상)
│   ├── ClaudeAgent.kt      설정·도구를 루프에 연결, 첫 메시지(시각·최근 대화·현재 화면·지시) 구성
│   ├── ToolDefs.kt         Claude에게 주는 도구 스키마 15개
│   ├── PhoneTools.kt       도구 실행(접근성/인텐트/알림), 보내기 전 확인
│   ├── SystemPrompt.kt     시스템 프롬프트 (STT 오류 보정, 안전 규칙, TTS용 답변 형식)
│   ├── AgentRuntime.kt     상태(대기/듣기/처리/말하기), 실행·중지, 되묻기(ask_user)
│   └── AppFinder.kt        "카톡", "유튜브" 같은 이름 → 설치된 앱
├── access/
│   ├── PhoneAccessibilityService.kt  터치·입력·스크롤·제스처·스크린샷(요소 번호 표시)
│   ├── ScreenReader.kt     접근성 트리 → "[12] Button "보내기" @540,2100 {click}" 목록
│   └── Bubble.kt           어느 앱 위에나 떠 있는 마이크 버튼
├── notify/                 알림 리스너 + 알림 RemoteInput으로 바로 답장
├── voice/                  SpeechRecognizer(ko-KR) 듣기 화면, TTS
└── ui/                     설정 화면, 빠른 설정 타일
```

- Claude 호출: 공식 Java SDK(`com.anthropic:anthropic-java`), 기본 모델 `claude-opus-5-5`, `effort` 기본 `low`(응답 속도 우선), 자동 프롬프트 캐싱, 안전 분류기가 거절할 때 서버가 다른 모델로 재시도하는 `fallbacks: "default"`(Haiku 제외).
- 화면을 바꾸는 도구(tap, type_text, open_app 등)는 실행 후 **바뀐 화면을 같이 돌려줘서** API 왕복 횟수를 줄입니다.
- 에이전트 루프는 Messages API를 휴대폰에서 직접 돌립니다. 도구가 전부 휴대폰 안(접근성 서비스)에서 실행되기 때문입니다.

### 빌드·테스트

JDK 17+와 Android SDK(platform 35)가 필요합니다.

```bash
cd voice-agent
./gradlew testDebugUnitTest   # 에이전트 루프·요청 형식·확인 판별 테스트 (가짜 API 서버 사용)
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

`voice-agent/**`가 바뀌어 푸시되면 GitHub Actions(`.github/workflows/phonebutler-apk.yml`)가 테스트 → APK 빌드 → `phonebutler-latest` Release에 올립니다.

### (선택) 고정 서명 키 — 업데이트 설치가 되게 하기

서명 키를 지정하지 않으면 빌드할 때마다 다른 임시 키로 서명되어, 새 버전을 설치하려면 이전 앱을 지워야 합니다. 한 번만 키를 만들어 저장소 **Settings → Secrets and variables → Actions**에 넣어 두면 업데이트 설치가 됩니다.

```bash
keytool -genkeypair -v -keystore release.jks -alias phonebutler -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks   # 출력값을 SIGNING_KEYSTORE_BASE64 에
```

| Secret | 값 |
| --- | --- |
| `SIGNING_KEYSTORE_BASE64` | 위 base64 출력 |
| `SIGNING_STORE_PASSWORD` | 키스토어 비밀번호 |
| `SIGNING_KEY_ALIAS` | `phonebutler` |
| `SIGNING_KEY_PASSWORD` | 키 비밀번호 |

`release.jks` 파일은 저장소에 올리지 마세요(.gitignore에 포함되어 있습니다).
