# 말로폰 — 말로 하는 폰 조작

안드로이드 폰에 말로 시키면 앱을 열고, 카카오톡 채팅방에 들어가 메시지를 보내고, 유튜브 영상을 틀어 주는 앱입니다.

| 이렇게 말하면 | 이렇게 합니다 |
| --- | --- |
| "카톡으로 엄마한테 오늘 늦어 라고 보내줘" | 카카오톡 → 엄마 채팅방 → "오늘 늦어" 입력 → 확인 창 → 전송 |
| "카톡 회사 단톡방 들어가줘" | 카카오톡에서 '회사' 채팅방을 찾아 엽니다 |
| "유튜브에서 아이유 좋은날 틀어줘" | 첫 번째 영상을 찾아 바로 재생합니다 |
| "인스타 켜줘", "네이버 지도 실행해줘" | 설치된 앱을 이름으로 찾아 엽니다 |
| "내일 아침 7시에 알람 맞춰줘", "10분 타이머" | 시계 앱에 알람·타이머를 맞춥니다 |
| "엄마한테 전화해줘" | 연락처에서 찾아 확인 후 전화합니다 |
| "뒤로 가", "홈으로" | 뒤로 가기, 홈 화면 |
| (AI 키가 있을 때) "인스타에서 첫 게시물 좋아요 눌러줘" | AI가 화면을 읽으며 직접 누르고 입력합니다 |

메시지는 **말한 그대로** 입력합니다. 끝의 "~라고", "~다고"만 떼어 냅니다("오늘 늦는다고" → "오늘 늦는다").

## 설치

1. 폰 브라우저에서 **https://github.com/ahnjs5576-cyber/gen/releases/tag/malophone-latest** 를 엽니다.
2. `malophone.apk`를 눌러 내려받고 엽니다. "출처를 알 수 없는 앱" 설치를 허용하라고 나오면 허용합니다.
3. 새 버전이 나오면 같은 방법으로 덮어 설치하면 됩니다(설정과 권한이 유지됩니다).

## 처음 설정 (앱 첫 화면에 순서대로 나옵니다)

1. **마이크 권한** 허용
2. **접근성 서비스 켜기**: 설정 → 접근성 → 설치된 앱 → "말로폰 음성 조작" 켜기.
   - Android 13 이상에서 "제한된 설정"이라며 켜지지 않으면:
     설정 → 애플리케이션 → 말로폰 → 오른쪽 위 ⋮ → **제한된 설정 허용** → 다시 켜기.
3. (선택) **Claude API 키**: [console.anthropic.com](https://console.anthropic.com)에서 발급해 앱 설정에 붙여 넣습니다.
   없어도 위 표의 정해진 명령은 동작합니다. 있으면 말을 더 자유롭게 알아듣고, 정해진 기능으로 안 되는 일도 AI가 화면을 보며 처리합니다.
   API 사용료는 본인 계정에 청구됩니다(설정에서 더 저렴한 모델을 고를 수 있습니다).
4. (선택) **연락처·전화 권한**: 이름으로 전화 걸 때 필요합니다.

## 부르는 방법

- **떠 있는 마이크 버튼**: 접근성을 켜면 화면 가장자리에 생깁니다. 누르면 듣기 시작, 실행 중에 누르면 멈춤, 길게 누르면 앱 열기. 끌어서 옮길 수 있습니다.
- **빠른 설정 타일**: 상단바를 내려 연필(편집) → "말로 명령" 타일을 추가합니다.
- **홈 버튼 길게 누르기**: 설정 → 애플리케이션 → 기본 앱 → 디지털 어시스턴트 앱 → 말로폰 (기기에 따라 없을 수 있습니다).
- **접근성 버튼**: 내비게이션 바의 접근성 버튼을 눌러도 듣기 시작합니다.
- 앱 안의 큰 마이크 버튼, 또는 글로 입력.

## 안전장치

- 카카오톡 전송과 전화 걸기 직전에 **확인 창**(보내기/취소)이 뜹니다. 설정에서 끌 수 있지만 권장하지 않습니다.
- AI 화면 조작 중에도 "전송·결제·삭제" 같은 버튼을 누르기 전에는 확인을 받습니다. 결제·송금·구매·계정 삭제는 하지 않도록 막혀 있습니다.
- 실행 중 언제든 떠 있는 버튼을 누르면 멈춥니다.

## 개인정보

- API 키와 설정은 이 폰의 앱 저장소에만 저장됩니다.
- 화면 내용은 **AI가 명령을 처리할 때만**, 그 순간 화면의 글자(버튼 이름 등)가 Claude API로 전송됩니다. 정해진 명령(규칙 해석)은 폰 안에서만 처리됩니다.
- 음성 인식은 폰의 기본 음성 인식 서비스(보통 Google)를 사용합니다.

## 알려진 한계

- 카카오톡은 공식 자동화 기능이 없어 화면을 읽고 대신 누르는 방식입니다. 카카오톡 업데이트로 화면 구조가 바뀌면 실패할 수 있고,
  이때 AI 키가 있으면 AI가 화면을 보며 이어서 처리합니다.
- 화면이 잠겨 있으면 다른 앱을 조작할 수 없습니다. 화면이 꺼진 상태에서 "헤이 ○○" 같은 호출어로 깨우는 기능은 없습니다.
- 은행 앱 등 일부 앱은 보안 때문에 자동 조작을 막습니다.
- 유튜브 영상은 검색 결과의 첫 번째 영상을 재생합니다. 설정에 YouTube Data API 키를 넣으면 더 정확합니다.

## 개발

```
voice-agent/
  app/src/main/java/com/malophone/agent/
    core/     명령 모델(Action), 라우터, 실행기, 설정, 상태, 확인 창 연결
    parse/    한국어 규칙 파서(오프라인), 한글 유사도·숫자 유틸
    a11y/     접근성 서비스, 화면 읽기(ScreenSnapshot), 터치·입력(UiDriver), 떠 있는 버튼·확인 창
    actions/  앱 실행, 유튜브, 카카오톡 자동화, 알람·타이머·전화·검색
    ai/       Claude API(공식 Java SDK) 해석기 + 화면 조작 에이전트
    voice/    음성 인식(SpeechRecognizer), 음성 안내(TTS)
    ui/       메인 화면, 듣기 창 / tile/ 빠른 설정 타일
  DESIGN.md   구조와 모듈 계약
```

- 빌드: GitHub Actions(`.github/workflows/malophone-android.yml`)가 이 폴더가 바뀔 때마다 단위 테스트를 돌리고 APK를 만들어
  `malophone-latest` 릴리스에 올립니다. 로컬에서는 Android SDK를 설치한 뒤 `./gradlew :app:assembleDebug`.
- 테스트 명령 보내기(adb): `adb shell am start -a com.malophone.agent.LISTEN --es text "유튜브에서 아이유 틀어줘"`
- 서명: 업데이트 설치가 끊기지 않도록 고정 디버그 키(`app/debug.keystore`, 공개 저장소에 있음)로 서명합니다.
  개인용 빌드이므로 이 저장소의 릴리스에서만 APK를 받으세요. 직접 배포하려면 자신만의 키로 바꾸세요.
