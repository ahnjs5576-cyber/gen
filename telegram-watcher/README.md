# 텔레그램 몰래보기 비서 (TG Watcher)

내 텔레그램 대화방을 **읽음 표시 없이** 자동으로 살펴보고,
핸드폰(안드로이드)에서 지시하면 처리해 주는 서비스입니다. 윈도우 PC에서 실행합니다.

- 새 메시지를 실시간으로 받아 로컬 DB에 기록 (상대방에게 읽음 표시 안 뜸)
- 감시 대화방, 키워드 알림을 핸드폰으로 즉시 전달
- "회사 단톡방 안 읽은 거 요약해줘" 같은 자연어 지시를 Claude가 처리
- 첨부파일도 읽음: 사진, PDF, 한글(HWP/HWPX), 워드·엑셀·파워포인트(docx/xlsx/pptx), 텍스트
- 메시지 전송은 `/yes`로 확인했을 때만 실행

## 왜 읽음 표시가 안 뜨나요?

텔레그램 **봇 API로는 내 개인 대화방을 읽을 수 없습니다.** 그래서 이 서비스는
내 계정으로 로그인하는 **MTProto 사용자 API**(Telethon 라이브러리)를 씁니다.

상대방 화면에 '읽음(✓✓)'이 뜨는 건 클라이언트가 서버에 `readHistory` 요청을
보낼 때뿐입니다. 이 서비스는 그 요청을 **한 번도 보내지 않습니다**
(`tg_reader.py`에 `mark_read` / `send_read_acknowledge` 호출이 없습니다). 그래서:

| 동작 | 읽음 표시 |
|---|---|
| 새 메시지 실시간 수신·기록 | ❌ 안 뜸 |
| 안 읽은 메시지 / 최근 메시지 조회, 검색 | ❌ 안 뜸 |
| 핸드폰에서 안 읽은 개수(빨간 뱃지) | 그대로 유지됨 |
| 이 서비스로 **메시지를 보냄** (`/yes`) | ⚠️ 그 방은 읽음 처리될 수 있음 |
| 내가 직접 텔레그램 앱에서 그 방을 열어봄 | ✅ 평소처럼 읽음 |

추가로 `KEEP_OFFLINE=true`면 시작할 때와 전송 후에 계정 상태를 '오프라인'으로
돌려놔서 '온라인' 표시가 남지 않게 합니다.

## 구조

```
안드로이드 텔레그램 앱
   │  (지시: "/unread 회사" 또는 "엄마한테 온 거 있어?")
   ▼
 내 지시용 봇 ──────► 윈도우 PC의 TG Watcher ──► Claude (자연어 지시 해석)
   ▲                     │  (내 계정으로 읽기 전용 조회, 읽음 처리 X)
   │ (결과·알림)          ▼
   └──────────────── 텔레그램 서버의 내 대화방들
```

## 설치 (윈도우)

### 0. 준비물
1. **Python 3.10 이상** — https://www.python.org/downloads/ 설치 시 *Add python.exe to PATH* 체크
2. **텔레그램 API 키** — https://my.telegram.org 로그인 → *API development tools* →
   앱 이름 아무거나 입력 → `api_id`, `api_hash` 복사
3. **지시용 봇 (권장)** — 텔레그램에서 `@BotFather` → `/newbot` → 봇 토큰 복사.
   그 다음 만든 봇과 대화방을 열고 `/start` 를 한 번 보내 두세요.
4. **Claude API 키 (선택)** — https://console.anthropic.com 에서 발급.
   없으면 `/명령어`만 쓸 수 있고, 자연어 지시는 안 됩니다.

### 1. 설치
이 폴더(`telegram-watcher`)를 PC에 받은 뒤 `setup.bat` 더블클릭 →
메모장이 열리면 `.env`에 위에서 받은 값을 채우고 저장합니다.

```
TG_API_ID=1234567
TG_API_HASH=0123456789abcdef...
TG_PHONE=+821012345678
BOT_TOKEN=7000000000:AAH...
ANTHROPIC_API_KEY=sk-ant-...
```

### 2. 첫 실행 (로그인)
`run.bat` 더블클릭 → 콘솔에 **텔레그램 앱으로 온 로그인 코드**를 입력합니다
(2단계 인증을 쓰면 비밀번호도). 로그인 정보는 `sessions/user.session`에 저장되어
다음부터는 묻지 않습니다.

봇으로 "✅ 텔레그램 감시를 시작했어요"가 오면 성공입니다.

### 3. 백그라운드 실행 / 자동 시작
- `start_background.bat` — 콘솔 창 없이 실행 (로그: `data/service.log`)
- `stop_background.bat` — 종료
- 부팅 시 자동 시작: `Win + R` → `shell:startup` → 열린 폴더에
  `start_background.bat`의 **바로가기**를 넣어두세요.

PC가 꺼져 있거나 절전 중이면 동작하지 않습니다. 24시간 돌리려면 PC 절전을 끄거나,
나중에 클라우드 서버(VPS)로 옮기면 됩니다(코드 그대로 동작).

## 사용법 (안드로이드)

내 지시용 봇에게 메시지를 보내면 됩니다. (봇 토큰을 안 넣었으면 텔레그램의
**저장한 메시지**에 `/명령어` 또는 `!할 일` 형식으로 보내세요. 단, 이 모드에선
알림이 핸드폰 푸시로 안 와서 봇 방식을 권장합니다.)

| 명령 | 설명 |
|---|---|
| `/unread` | 안 읽은 메시지가 있는 방 목록 |
| `/unread 회사` | '회사'가 들어간 방의 안 읽은 메시지 (읽음 처리 X) |
| `/recent 가족 30` | 최근 30개 메시지 |
| `/chats 스터디` | 대화방 검색 |
| `/search 계약서` | 전체 대화방에서 검색 |
| `/file 회사 1234` | 메시지 뒤 `⟨#1234⟩` 첨부파일의 글자 보기 (한글·워드·엑셀·PDF 등) |
| `/watch 회사` · `/unwatch 회사` · `/watchlist` | 새 메시지 오면 즉시 알려줄 방 |
| `/kw 급함` · `/unkw 급함` · `/kwlist` | 어느 방이든 이 단어가 나오면 알림 |
| `/yes` · `/no` | Claude가 준비한 메시지 전송 / 취소 |
| `/reset` | Claude 대화 맥락 초기화 |

자연어 예시 (Claude 키가 있을 때, 음성 입력도 OK):
- "회사 단톡방 오늘 안 읽은 거 세 줄로 요약해줘"
- "어제부터 나 언급된 메시지 있어?"
- "스터디방 감시 걸어주고 '마감'이라는 단어 나오면 알려줘"
- "김과장한테 '확인했습니다' 라고 보내줘" → 미리보기 후 `/yes`로 전송
- "회사방에 올라온 한글 파일 내용 정리해줘", "가족방 마지막 사진 뭐야?"

첨부파일 참고: 음성메시지·동영상 내용은 아직 못 읽어요(동영상은 미리보기 장면 한 장만).
예전 형식(.doc/.xls/.ppt), 암호 걸린 한글 문서, 20MB 넘는 파일도 못 읽어요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 실행 진입점: 로그인, 실시간 감시, 봇 명령 처리 |
| `tg_reader.py` | 읽음 처리 없이 조회하는 함수 모음 (유일한 전송 함수 `send_text`) |
| `attachments.py` | 첨부파일 읽기 (사진·PDF·HWP/HWPX·docx/xlsx/pptx·텍스트) |
| `agent.py` | Claude 도구 사용 루프 (자연어 지시 → 텔레그램 조회 도구 호출) |
| `storage.py` | SQLite: 수신 로그, 감시 방, 키워드 (`data/messages.db`) |
| `config.py` | `.env` 로딩 |

## ⚠️ 보안·주의사항

- **`sessions/user.session` 파일 = 내 텔레그램 계정 전체 권한**입니다.
  절대 공유하거나 깃허브에 올리지 마세요(`.gitignore`에 포함됨). 유출이 의심되면
  텔레그램 앱 → 설정 → 기기 에서 "TG Watcher" 세션을 종료하세요.
- `.env`의 API 키들도 마찬가지로 비공개로 관리하세요.
- 지시용 봇은 **내 계정이 보낸 메시지에만** 반응합니다(다른 사람이 봇을 찾아 말 걸어도 무시).
- 대화방 메시지 안에 "OO에게 보내라" 같은 문장이 있어도 Claude는 따르지 않도록 되어 있고,
  전송은 항상 `/yes` 확인이 필요합니다.
- 자연어 지시를 쓰면 조회한 메시지 내용이 Claude API로 전송됩니다. 민감한 방이 있다면
  `/명령어`만 쓰세요(명령어는 PC 안에서만 처리됩니다).
- 사용자 API 자동화는 텔레그램 약관상 허용되지만, 스팸성 대량 전송을 하면 계정이
  제한될 수 있습니다. 이 서비스는 읽기 위주라 일반적인 사용엔 문제없습니다.
