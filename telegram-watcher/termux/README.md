# 안드로이드(Termux)에서 PC 없이 돌리기

폰 하나로 24시간 텔레그램을 감시하고, 같은 폰의 텔레그램 앱으로 봇에게 지시하는 방법입니다.

> ⚠️ **Termux와 Termux:Boot는 같은 곳에서 받아야 합니다** (둘 다 F-Droid, 또는 둘 다 GitHub).
> 받은 곳이 다르면 서명이 달라서 Termux:Boot가 동작하지 않아요. Play 스토어 버전은 쓰지 마세요.

---

## 0단계. 키 준비 (폰 브라우저로)

1. **텔레그램 API 키**: https://my.telegram.org → 전화번호로 로그인(코드는 텔레그램 앱으로 옴)
   → *API development tools* → App title·Short name 아무거나 → `api_id`(숫자), `api_hash` 복사해 두기
2. **지시용 봇**: 텔레그램에서 `@BotFather` 검색 → `/newbot` → 이름 정하기 → **토큰** 복사
   → 방금 만든 봇 대화방을 열고 **`/start`** 한 번 보내기
3. (선택) **Claude API 키**: https://console.anthropic.com → API Keys

## 1단계. 앱 준비

1. **Termux:Boot 앱을 한 번 실행**했다가 닫기 (한 번 열어야 부팅 자동 시작이 활성화됨)
2. **Termux 앱 실행** → 알림 권한을 물으면 **허용** (백그라운드 유지에 필요)

## 2단계. 설치 (Termux 화면에 복사·붙여넣기)

아래 두 줄을 그대로 붙여넣고 Enter. (길게 누르기 → Paste)

```bash
pkg install -y git && git clone --depth 1 -b claude/telegram-auto-monitoring-nbgpub https://github.com/ahnjs5576-cyber/gen.git ~/tg-watcher
bash ~/tg-watcher/telegram-watcher/termux/install.sh
```

- 중간에 `[Y/n]`이나 설정 파일 질문이 나오면 그냥 **Enter**
- "Claude 자연어 기능 설치할까요?" → 쓰려면 `y` (폰에서 빌드하느라 **10~30분**, 저장공간 약 1.5GB).
  나중에 `tgw claude`로 설치해도 됩니다.
- 마지막에 `✅ 설치 완료!`가 나오면 성공

## 3단계. 설정 → 로그인 → 실행

```bash
tgw setup
```
0단계에서 복사한 값을 하나씩 붙여넣고 Enter (비밀값은 화면에 안 보이는 게 정상).

```bash
tgw login
```
텔레그램 앱으로 온 **로그인 코드**를 입력 (2단계 인증을 쓰면 비밀번호도).
봇에서 **"✅ 텔레그램 감시를 시작했어요"**가 오면 성공 → 볼륨 아래 + `C` (= Ctrl+C) 로 종료.

```bash
tgw start
```
이제 백그라운드에서 돌아갑니다. Termux 앱은 닫아도 돼요(알림창에 Termux 표시가 남아 있으면 정상).

## 4단계. 꺼지지 않게 폰 설정 (중요!)

안드로이드는 배터리 절약을 위해 백그라운드 앱을 자주 꺼버립니다. 아래를 꼭 해 주세요.

1. **배터리 최적화 끄기**
   설정 → 애플리케이션 → **Termux** → 배터리 → **제한 없음**
   **Termux:Boot**도 똑같이.
2. **(삼성)** 설정 → 배터리 → 백그라운드 사용 제한 → **"사용 안 하는 앱을 절전 상태로 전환" 끄기**,
   그리고 **"절전 예외 앱"**에 Termux, Termux:Boot 추가
3. **(안드로이드 12 이상) 하위 프로세스 제한 끄기**
   - 개발자 옵션 켜기: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번 탭**
   - 설정 → 개발자 옵션 → **"하위 프로세스 제한 사용 중지"** 켜기 (안드로이드 14 이상)
   - 이 메뉴가 없으면 알려주세요. PC와 연결해서 adb 명령으로 설정해야 합니다.

## 5단계. 확인

1. 텔레그램에서 봇에게 `/help` → 명령어 목록이 오면 OK
2. `/unread` → 안 읽은 방 목록이 오는지, **상대방 쪽에 읽음 표시가 안 뜨는지** 확인
3. **폰 재부팅** → 1분쯤 기다렸다 봇에게 `/help` → 답이 오면 자동 시작도 OK

## 관리 명령

| 명령 | 설명 |
|---|---|
| `tgw status` | 실행 상태 + 최근 로그 |
| `tgw log` | 실시간 로그 (나가기: Ctrl+C) |
| `tgw stop` / `tgw start` / `tgw restart` | 멈춤 / 실행 / 재시작 |
| `tgw setup` | 키·토큰 다시 입력 |
| `tgw update` | 최신 코드로 업데이트 |
| `tgw claude` | Claude 자연어 기능 설치 (나중에 할 때) |

## 문제 해결

- **`pkg` 할 때 저장소 오류** → `termux-change-repo` 실행 → 다른 미러 선택 후 다시 시도
- **자꾸 꺼짐** → 4단계 다시 확인. `tgw log`에서 마지막 기록 시간 확인
- **봇이 답을 안 함** → `tgw status`가 🟢인지 확인, 봇에게 `/start`를 보냈는지 확인
- **anthropic 설치 실패** → 명령어(`/unread` 등)는 그대로 쓸 수 있어요. 오류 메시지를 알려주세요.

## 🔒 보안 메모

- 로그인 정보(`~/tg-watcher/telegram-watcher/sessions/`)와 `.env`는 Termux 앱 전용 저장공간에
  있어서 다른 앱은 읽을 수 없습니다(루팅 안 된 폰 기준). `.env`는 본인만 읽을 수 있게 권한도 잠가 둡니다.
- 코드 저장소는 공개지만 **키·로그인 정보는 저장소에 올라가지 않습니다** (폰에만 있음).
- 폰 화면 잠금은 꼭 켜두세요. 폰을 잃어버리면 다른 기기의 텔레그램 → 설정 → 기기 에서
  **"TG Watcher"** 세션을 종료하세요.
- 텔레그램 2단계 인증(설정 → 개인정보 및 보안)도 켜두는 걸 권장합니다.
