# kakao-reply

카카오톡 대화를 읽고 **요약 + 답장 초안**을 만들어 주는 로컬 도구입니다.

## 전체 구조

읽기 · 초안 작성 · 입력을 서로 다른 모듈로 나눴습니다.

```
카카오톡 앱 (서버와 동기화)
   │  사용자가 '대화 내보내기'
   ▼
내보내기 파일 (.txt/.csv) ──► [읽기] parser.py ──► [정리] transcript.py ──► [초안] analyzer.py ──► [입력] output.py
   읽기 전용으로만 열기          시간순 정렬, 첨부 분리     답장 필요 여부,          Claude API            클립보드 복사까지만
                                                       신선도 계산                                    (전송은 사용자가 직접)
```

## 설계 원칙과 이 도구에서 지킨 방식

| # | 원칙 | 이 도구에서 |
|---|---|---|
| 1 | 앱이 저장한 데이터를 원본으로 | 카카오톡 공식 **대화 내보내기** 파일을 씁니다 |
| 2 | 읽기 전용 | 파일을 읽기 모드로만 열고, 쓰거나 고치지 않습니다 |
| 3 | 암호화 우회 금지 | 맥 카카오톡 로컬 DB는 암호화돼 있고 카카오가 키를 공식 제공하지 않으므로 **DB를 직접 열지 않습니다**. 공식 경로가 생기면 `parser.py` 와 같은 `Chat` 을 돌려주는 리더만 추가하면 됩니다 |
| 4 | 읽기 쉬운 형태 | 시간순 정렬, 방별 마지막 발신자, **마지막이 내 메시지인지**, 답 안 한 메시지 수(`inbox`, `show`). 내보내기에는 읽음 표시가 없어서 '안 읽은 위치'는 **내 마지막 메시지 이후**로 계산합니다 |
| 5 | 화면 조작 없이 읽기 | 파일만 읽습니다. 화면 캡처·마우스 제어 없음 |
| 6 | 최신성은 앱 동기화에 의존 | 파일 머리말의 '저장한 날짜'를 읽어 1시간이 넘으면 "그 뒤 대화는 빠져 있음"이라고 경고합니다 |
| 7 | 첨부는 본문과 분리 | `사진`, `파일: …` 등은 첨부 자리표시로 따로 표시합니다. 내보내기에는 원본·링크가 없으므로 **받을 수 없다고 안내**합니다 |
| 8 | 입력은 별도 모듈 | `output.py` 는 초안을 **클립보드에 복사**만 합니다. 카톡 창을 열지 않으니 읽음 처리도 없고, 전송은 사용자가 직접 합니다 |
| 9 | 개인정보 보호 | 기간(`--days`)·개수(`--last`)만큼만 사용 · 대화록을 디스크에 저장하지 않음 · 로그에는 개수만 기록 · `--pseudonymize` 로 이름을 가명으로, 전화번호·이메일·계좌번호 등을 가린 뒤 전송 · API 키는 macOS 키체인 · `--dry-run` 으로 전송 내용 미리 보기 |

## 설치

```bash
cd kakao-reply
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
kakao-reply key set        # API 키를 키체인에 저장 (또는 ANTHROPIC_API_KEY 환경변수)
```

## 대화 내보내기 방법

- **Mac/PC**: 대화방 → 우측 상단 메뉴(≡) → 대화 내용 → 대화 내보내기 (텍스트 또는 CSV)
- **모바일**: 대화방 → 메뉴 → 설정(⚙) → 대화 내용 내보내기 → 텍스트만 보내기

내보낸 파일은 `exports/` 폴더 하나에 모아 두면 편합니다 (이 폴더는 git 에서 제외됨).
카카오톡 버전에 따라 메뉴 위치와 파일 형식이 조금 다를 수 있습니다. 파싱이 안 되면 파일 앞부분 몇 줄(개인정보는 가리고)을 알려 주세요.

## 사용

```bash
# 여러 방을 최근순으로 한눈에
kakao-reply inbox exports/ --me 철수

# 한 방의 상태 + 내가 아직 답 안 한 메시지
kakao-reply show exports/민수.txt --me 철수

# 요약과 답장 초안 3개, 1번을 클립보드로
kakao-reply suggest exports/민수.txt --me 철수 --copy 1

# 이름·번호를 가리고, 최근 3일만, 추가 요청과 함께
kakao-reply suggest exports/팀.txt --me 철수 --days 3 --pseudonymize --ask "내일 오전은 어렵다고 정중하게"

# 실제로 보낼 내용만 확인 (API 호출 안 함)
kakao-reply suggest exports/민수.txt --me 철수 --pseudonymize --dry-run
```

`--me` 는 내보낸 파일에 표시된 본인 이름입니다. 파일에 `나`로 찍혀 있으면 생략해도 됩니다.

`inbox` 출력 예:

```
방                 마지막       마지막 발신  답할 것  비고
민수               11-06 21:16  민수         2        답장 필요, 첨부 1
팀 프로젝트        11-06 16:40  현우         1        답장 필요, 10시간 전 내보냄
```

`suggest` 출력 예:

```
■ 요약
민수가 토요일 점심 약속을 제안했고, 12시 강남역을 물어본 상태.

■ 답해야 할 것
  - 12시 강남역 괜찮은지
  - 가고 싶은 식당

■ 답장 초안
  1. [가볍게] 좋아 12시 강남역 콜! 먹고 싶은 거 있어?
  2. [제안형] 12시 좋아~ 근처에 [식당] 어때?
  3. [시간 조정] 혹시 12시 반 괜찮아? 조금 늦을 수도 있어서

1번 초안을 클립보드에 복사했어요. 카카오톡에서 붙여넣고 직접 보내세요.
```

## 모듈

```
kakao_reply/
  parser.py      [읽기] 내보내기 파서 (PC·Android·iOS 텍스트, CSV), 저장 시각, 첨부 판별
  transcript.py  [정리] 방 상태: 마지막이 내 메시지인지, 답 안 한 메시지, 기간 필터, 신선도
  analyzer.py    [초안] Claude API — JSON 스키마로 요약/답할 것/답장 초안
  privacy.py     가명 처리·식별정보 가림·로그용 요약
  output.py      [입력] 클립보드 복사 (읽기 모듈과 분리)
  secrets.py     키체인에서 API 키 조회·저장
  cli.py         명령줄 인터페이스
tests/           unittest + 형식별 샘플 파일
```

- 모델: `claude-opus-5-5`, effort `medium`. 안전 분류기가 거절하면 서버 측 fallback(`fallbacks: "default"`)으로 다른 모델이 이어 받습니다.
- 대화 내용은 `<chat>` 태그 안의 **데이터**로만 다루도록 지시해, 대화 속 문장이 지시문처럼 동작하지 않게 합니다.
- 접근성 API 로 입력창에 직접 넣는 기능은 대화방을 열어 읽음 처리를 일으킬 수 있어 넣지 않았습니다. 추가한다면 `output.py` 안에서, 명시적으로 켰을 때만, 전송 키는 누르지 않는 방식으로 만듭니다.
