# kakao-reply

카카오톡 대화를 읽고 **요약 + 답장 초안**을 만들어 주는 컴퓨터용(맥·윈도우·리눅스) 도구입니다.

## 전체 구조

읽기 · 초안 작성 · 입력을 서로 다른 모듈로 나눴습니다.

```
카카오톡 앱 (서버와 동기화)
   │  사용자가 '대화 내보내기'
   ▼
내보내기 파일 ──► [읽기] parser.py ──► [정리] transcript.py ──► [보호] privacy.py ──► [초안] analyzer.py ──► [입력] output.py
 (.txt/.csv)      읽기 전용,           시간순, 답 안 한 메시지,   가명·번호 가림        Claude API             클립보드 복사까지만
                  인코딩 자동 판별      첨부 분리, 신선도          (기본값)                                     (전송은 사용자가 직접)
```

## 설계 원칙과 이 도구에서 지킨 방식

| # | 원칙 | 이 도구에서 |
|---|---|---|
| 1 | 앱이 저장한 데이터를 원본으로 | 카카오톡 공식 **대화 내보내기** 파일을 씁니다 |
| 2 | 읽기 전용 | 파일을 읽기만 하고, 쓰거나 고치지 않습니다 |
| 3 | 암호화 우회 금지 | 맥 카카오톡 로컬 DB는 암호화돼 있고 카카오가 키를 공식 제공하지 않으므로 **DB를 직접 열지 않습니다**. 공식 경로가 생기면 같은 `Chat` 을 돌려주는 리더만 추가하면 됩니다 |
| 4 | 읽기 쉬운 형태 | 시간순 정렬, 방별 마지막 발신자, **마지막이 내 메시지인지**, 답 안 한 메시지 수. 내보내기에는 읽음 표시가 없어서 '안 읽은 위치'는 **내 마지막 메시지 이후**로 계산합니다 |
| 5 | 화면 조작 없이 읽기 | 파일만 읽습니다. 화면 캡처·마우스 제어 없음 |
| 6 | 최신성은 앱 동기화에 의존 | 파일의 '저장한 날짜'를 읽어 1시간이 넘으면 "그 뒤 대화는 빠져 있음"이라고 경고합니다 |
| 7 | 첨부는 본문과 분리 | `사진`, `파일: …` 등은 첨부로 따로 표시합니다. 내보내기에는 원본·링크가 없으므로 **받을 수 없다고 안내**하고, 모델에게도 본 척하지 말라고 지시합니다 |
| 8 | 입력은 별도 모듈 | `output.py` 는 고른 초안을 **클립보드에 복사**만 합니다. 이 도구는 카톡 창을 열거나 조작하지 않고, 전송은 사용자가 직접 합니다. 단, **대화를 내보내려면 카카오톡에서 그 방을 열어야 하므로 그때 읽음 처리됩니다** (아래 '알려진 한계') |
| 9 | 개인정보 보호 | 아래 '개인정보' 절 참고 |

## 설치

**준비물**: Python 3.10 이상, Anthropic API 키.

1. **Python 확인** — 터미널에서 `python3 --version`. **윈도우는 아래 명령의 `python3` 를 모두 `py` 로 바꿔 쓰세요** (`python3` 를 치면 Microsoft Store 가 열릴 수 있음).
   3.10 미만이면 맥은 `brew install python`, 윈도우는 python.org 에서 설치(“Add to PATH” 체크).
2. **API 키 만들기** — <https://console.anthropic.com> 가입 → 결제 수단 등록 → *API Keys* → *Create Key*.
   요금은 쓴 만큼 나갑니다. 메시지 200개짜리 대화 한 번에 대략 **50~200원** 정도입니다(대화 길이에 따라 다름).
3. **설치**

   **가장 쉬운 방법**: 저장소를 내려받아(GitHub 의 *Code → Download ZIP* 후 압축 풀기, 또는 `git clone`) `kakao-reply` 폴더에서
   맥/리눅스는 `bash install.sh`, 윈도우는 `powershell -ExecutionPolicy Bypass -File install.ps1` 을 실행하세요.
   Python 버전 확인, pipx 설치, 프로그램 설치를 한 번에 합니다. Homebrew·Debian 처럼 pip 설치가 막힌 Python(PEP 668)이면
   Homebrew 의 pipx 를 쓰거나, 그것도 없으면 전용 가상환경(`~/.local/share/kakao-reply`)에 설치합니다.

   한 줄로 설치 (git 필요, 기본 브랜치에 합쳐진 뒤):

   ```bash
   python3 -m pip install --user pipx && python3 -m pipx ensurepath   # pipx 가 없을 때 한 번만, 그 뒤 터미널을 새로 열기
   pipx install "git+https://github.com/ahnjs5576-cyber/gen.git#subdirectory=kakao-reply"
   ```

   직접 받아서 설치하려면: `git clone https://github.com/ahnjs5576-cyber/gen.git && cd gen/kakao-reply && pipx install .`

4. **처음 한 번 설정**

   ```bash
   kakao-reply key set     # API 키 붙여넣기 (화면에 표시되지 않음). 맥 키체인/윈도우 자격 증명 관리자에 저장
   kakao-reply me 철수     # 내보낸 파일에 찍히는 본인 이름
   ```

API 키는 `kakao-reply key set` 으로 저장하는 것을 권장합니다. `ANTHROPIC_API_KEY` 환경변수도 동작하지만 `.zshrc` 같은 평문 파일에 남기 쉽습니다.

## 대화 내보내기 방법

- **Mac/PC (권장)**: 대화방 → 우측 상단 메뉴(≡) → 대화 내용 → 대화 내보내기 → 컴퓨터에 바로 저장. **CSV 를 고를 수 있으면 CSV 를 권장**합니다(아래 '알려진 한계' 참고).
- **모바일**: 대화방 → 메뉴 → 설정(⚙) → 대화 내용 내보내기 → 텍스트만 보내기. 이때 메일·클라우드 등 **다른 앱을 거쳐** 전달되니, 가능하면 PC/Mac 에서 내보내세요.

내보낸 파일은 `exports/` 폴더 하나에 모아 두면 편합니다 (git 에서 제외됨). **다 쓴 파일은 지우는 걸 권장합니다.**
읽을 수 있는 형식 (한국어 설정 기준, 오전/오후 12시간제·24시간제 모두):

| 형식 | 메시지 줄 모양 |
|---|---|
| PC/Mac 텍스트 | `[민수] [오후 7:02] 내용` (날짜는 `----- 2026년 11월 6일 금요일 -----`) |
| Android 텍스트 | `2026년 11월 6일 오후 7:02, 민수 : 내용` |
| iOS 텍스트 | `2026. 11. 6. 오후 7:02, 민수 : 내용` |
| CSV | `Date,User,Message` 머리줄 (파일 이름 `KakaoTalk_Chat_방이름_날짜.csv` 에서 방 이름·내보낸 시각을 읽음) |

영어 등 다른 언어 설정으로 내보낸 파일은 아직 읽지 못합니다. 파싱이 안 되면 파일 앞부분 몇 줄(개인정보는 가리고)을 알려 주세요.

## 사용

```bash
kakao-reply inbox exports/                     # 여러 방을 최근순으로 한눈에
kakao-reply show exports/민수.txt              # 한 방의 상태 + 내가 아직 답 안 한 메시지
kakao-reply suggest exports/민수.txt           # 요약 + 답장 초안 3개 → 번호를 고르면 클립보드로
kakao-reply suggest exports/팀.txt --days 3 --ask "내일 오전은 어렵다고 정중하게"
kakao-reply suggest exports/민수.txt --dry-run # 실제로 보낼 대화를 가명 처리된 그대로 확인 (API 호출 안 함, --json 은 요청 전체)
```

`inbox` 출력 예 (파일 이름은 `suggest` 에 그대로 붙여 넣을 수 있게 자르지 않습니다):

```
방                 마지막       마지막 발신  답할 것  파일                                         비고
민수               11-06 21:16  민수         2        KakaoTalk_Chat_민수_2026-11-06-22-10-03.csv  답장 필요, 첨부 1
팀 프로젝트        11-06 16:40  현우         1        팀프로젝트.txt                               답장 필요, 10시간 전 내보냄
엄마               11-06 18:21  엄마         ?        엄마.txt                                     본인 메시지 없음

답장 초안: kakao-reply suggest "exports/KakaoTalk_Chat_민수_2026-11-06-22-10-03.csv"  (맨 위 방 예시)
```

'답할 것' 이 `?` 이면 그 방에서 내 메시지를 찾지 못해 안 읽은 위치를 알 수 없다는 뜻입니다. '첨부' 는 사진·동영상·파일·음성처럼 원본이 따로 있는 것만 셉니다.

`suggest` 출력 예:

```
■ 요약
민수가 토요일 점심 약속을 제안했고, 12시 강남역에서 볼지 물어본 상태. 사진도 하나 보냈다.

■ 답해야 할 것
  - 민수: 12시 강남역 괜찮은지
  - 민수: 가고 싶은 식당이 있는지

■ 답장 초안
  1. [수락] 좋아 12시 강남역 콜! 먹고 싶은 거 있어?
  2. [대안 제시] 12시 좋아~ 근처에 [식당] 어때?
     ↳ 채워 넣을 것: 식당
  3. [시간 조정] 혹시 [시간]으로 미뤄도 돼?
     ↳ 채워 넣을 것: 시간

복사할 번호 (1-3, Enter=건너뛰기): 1
1번 초안을 클립보드에 복사했어요. 카카오톡에서 붙여넣고 직접 보내세요.
```

세 초안은 말투만 다른 게 아니라 **수락 / 대안 / 보류·거절**처럼 방향이 다르게 나옵니다. 모르는 사실은 지어내지 않고 `[시간]` 같은 빈칸으로 남깁니다.

## 개인정보

- **기본으로 가명 처리**: 전송 전에 참여자 이름 → `상대1`, `상대2`, 본인 이름 → `[본인]`. '김민수'·'김민수 대리'·'민수(회사)'·'🐶민수94'·'황보지은' 같은 닉네임에서 '민수', '지은'을 뽑아 '민수가', '민수였는데', '민수한텐', '김민수 대리님'처럼 본문에 나온 꼴까지 가립니다(영문은 대소문자 무시). 저장한 본인 이름(`kakao-reply me`)이 파일의 '나'와 달라도 본문 속 본인 이름을 가립니다. 1:1 방 제목(내가 저장한 상대 이름)도 그 사람으로 봅니다. 이름 뒤에 조사가 붙거나 아무것도 붙지 않을 때만 바꾸므로 '지수함수'처럼 단어 일부가 바뀌지는 않습니다. 이름이 흔한 낱말('하나', '우리', '지원', '수정' 등 목록에 있는 것)이면 부르는 꼴('하나야')에서만 바꿉니다. 단체방 제목은 그대로 둡니다.
- **되돌릴 때 조사도 고침**: 받은 초안의 `상대1아`, `상대1은` 은 실제 이름 받침에 맞게 `민수야`, `김민수는` 으로 바꿉니다. 직함·장식은 빼고(`김민수 대리` → `김민수`), 부를 때는 성을 뺀 이름을 씁니다.
- **관계·직함 힌트**: 닉네임에 '엄마', '팀장' 같은 말이 있으면 `상대1(엄마)`, `상대2(팀장)` 처럼 붙여 보내 모델이 존댓말·호칭을 고를 수 있게 합니다(사람을 특정하지 않는 말만). 닉네임이 '엄마' 뿐이면 본문의 '엄마' 는 바꾸지 않습니다.
- **번호 가림**: 전화번호·이메일·계좌/카드번호·주민/외국인등록번호처럼 보이는 문자열은 `[전화번호]` 등으로 가립니다(띄어 쓰거나 조사를 붙여 쓴 꼴 포함, 날짜·금액은 그대로). 가린 번호는 되돌리지 않습니다.
- 가명 처리를 끄려면 `--no-pseudonymize`.
- **아이디·링크·생년월일**: `카톡 아이디 minsu_kim94`, `@minsu_94`, 오픈채팅·인스타그램 등 프로필 링크, `1999년 3월 2일생` 은 `[아이디]`, `[프로필링크]`, `[생년월일]` 로 바꿉니다.
- **`[이름]` 은 한 가지**: 대화에 없는 사람·아이 이름은 모두 같은 `[이름]` 으로 바뀌어, 모델은 서로 다른 사람인지 구별하지 못합니다(되돌리지도 않음).
- **대화에 없는 사람**: `영희씨도 합류해요`, `지혜씨`, `이영희님`, `김영희 과장님께` 처럼 참여자가 아닌 사람을 'OO씨/OO님'·'성+이름 직함' 으로 부르면 `[이름]` 으로 가립니다. 부모님·교장님·기자님·고객님 같은 호칭, '김과장님' 같은 성+직함, '아가씨'·'솜씨' 같은 낱말은 그대로 둡니다.
- **학부모 닉네임**: '서준 엄마', '준서맘', '하린할머니', '하준이네', '윤서담임선생님' 의 '서준', '하린' 등은 그 사람이 아니라 아이 이름이라 `[이름]` 으로 가리고, 관계는 `상대1(○○엄마)` 로만 알려 줍니다. '엄마 김영희', '와이프 김지수' 처럼 그 사람 자신의 관계면 `상대1(엄마)` 입니다.
- **닉네임 속 설명**: '삼성전자 김지은', '김지은 퇴사', '박지성 선수', '민수 (부재중)' 처럼 회사·상태·직업 낱말은 이름으로 보지 않아 본문의 '삼성전자', '퇴사' 는 그대로 남습니다.
- **첨부 이름**: `파일: 홍길동_이력서.pdf` 처럼 파일 이름에 남의 이름이 들어가기 쉬워 `파일: [파일명].pdf` 로, 연락처 카드는 `연락처: [이름]` 으로 바꿔 보냅니다.
- **가리지 못하는 것**: 대화에 참여하지 않은 제3자를 호칭 없이 부를 때("지은이도 온대", "지호 엄마"), 한글 이름의 로마자 표기('LEE JI EUN', 'Ji-eun')와 본문의 한글 이름을 서로 잇는 것, LinkedIn·GitHub 같은 기타 프로필 링크, 영문 닉네임('Minsu')인 사람을 한글로 부를 때('민수야' — 1:1 방 제목이 한글 이름이면 가려짐), 성+직함만 쓴 호칭('박 과장'). 반대로 성 한 글자+이름 꼴은 낱말과 겹치면 잘못 바뀔 수 있습니다(참여자 '민수' 가 있을 때 '주민수가 늘었다'), 참여자 이름을 나열한 단체방 기본 제목에 들어 있는 '말하지 않은 사람'의 이름, 한 글자 이름, 흔한 낱말과 같은 이름이 부르는 꼴이 아닐 때("수정 고마워"), 목록에 없는 흔한 낱말 이름이 낱말로 쓰일 때 잘못 바뀌는 경우, 한글 이메일 주소, 주소처럼 형식이 정해지지 않은 정보. 반대로 사업자번호 같은 10자리 이상 숫자는 계좌/카드번호로 가려질 수 있습니다. 민감한 방은 `--dry-run` 으로 먼저 확인하세요.
- **필요한 만큼만**: 기본은 **마지막 메시지 기준 30일 안의 최근 200개**만 보냅니다. `--days N` (지금 기준 N일), `--last N` 으로 조절하고, `--dry-run` 첫 줄에 실제 범위가 나옵니다.
- **남기지 않는 것**: 대화록을 디스크에 저장하지 않습니다. 로그(`-v`)에는 개수만 남깁니다. 설정 파일(`~/.config/kakao-reply/config.json`)에는 본인 이름만 저장합니다.
- **남을 수 있는 것**: 클립보드 기록(클립보드 관리 앱·기기 간 동기화), 터미널 화면 기록, 셸 히스토리의 `--ask` 문구와 파일 이름. 민감하면 `--ask` 대신 실행 후 직접 입력하거나 히스토리를 지우세요.
- **외부로 나가는 것**: Claude API(Anthropic)로 위 범위의 대화만 전송합니다. 안전 분류기가 거절하면 Anthropic 안의 다른 Claude 모델로 자동 재시도합니다(`fallbacks: "default"`).

## 알려진 한계

- **텍스트(.txt) 내보내기의 가짜 줄**: 텍스트 형식은 여러 줄 메시지와 새 메시지를 줄 모양으로만 구분합니다. 상대가 메시지 안에 `[철수] [오후 9:16] 응 빌려줄게` 처럼 머리줄 모양을 직접 써 넣으면, 파일 자체에서 진짜 메시지와 구별할 수 없습니다. CSV 형식은 칸이 따옴표로 나뉘어 이런 문제가 없으니 가능하면 CSV 로 내보내세요. 이상하면 `show` 로 원문을 확인하세요.
- **읽음 처리**: 이 도구 자체는 읽음 처리를 일으키지 않지만, 카카오톡에서 대화를 내보내려면 방을 열어야 해서 **내보내는 순간 상대에게 읽음으로 표시됩니다**. 이건 피할 방법이 없으니, 읽어도 될 때 내보내세요.
- **읽음 위치**: 내보내기에는 읽음 표시가 없어 '내 마지막 메시지 이후'를 안 읽은 위치로 봅니다. 내가 사진·이모티콘만 보냈다면 답한 것으로 보지 않고, 그 앞의 질문도 모델이 함께 살핍니다. 그 방에서 내 메시지를 못 찾으면 `show`/`inbox` 는 안 읽은 위치를 `?` 로 표시합니다.
- **최신성**: 내보낸 뒤 온 메시지는 볼 수 없습니다. 내보낸 시각을 파일에서 찾지 못하면 파일 수정 시각으로 추정하고 '(추정)'이라고 표시합니다.
- **첨부물**: 사진·파일·위치·송금 등은 종류만 알 수 있고 원본은 없습니다.
- **말투 예시**: 보낼 범위(`--last`, 기본 최근 200개) 안의 내 메시지만 말투 예시로 씁니다. 바쁜 단체방에서 그 안에 내 메시지가 없으면 상대 말투에 맞춰 무난하게 씁니다. 범위를 넓히려면 `--last 500` 처럼 늘리세요(그만큼 더 많이 전송됨).
- **마지막이 내 메시지일 때**: 상대가 아직 답하지 않은 상태라 `suggest` 는 바로 초안을 만들지 않습니다. 한 번 더 보낼 말이 필요하면 `--ask` 로 원하는 내용을 적어 주세요.

## 모듈

```
kakao_reply/
  parser.py      [읽기] 내보내기 파서 (PC·Android·iOS 텍스트, CSV), 저장 시각, 첨부·시스템 메시지 판별, UTF-8/CP949/UTF-16
  transcript.py  [정리] 방 상태: 마지막이 내 메시지인지, 답 안 한 메시지, 기간 필터, 신선도, 본인 추정
  privacy.py     [보호] 가명 처리·식별정보 가림·로그용 요약
  analyzer.py    [초안] Claude API — 메시지를 JSON 줄로 보내 주입을 막고, 답 안 한 메시지·내 말투 예시를 따로 전달
  output.py      [입력] 클립보드 복사 (읽기 모듈과 분리)
  secrets.py     키체인에서 API 키 조회·저장
  config.py      본인 이름 저장
  cli.py         명령줄 인터페이스
tests/           unittest + 형식별 샘플 파일
```

- 모델: `claude-opus-5-5`, effort `medium`, JSON 스키마 구조화 출력.
- 대화는 메시지마다 JSON 한 줄로 보내고 `<`, `>` 를 이스케이프합니다. 메시지 본문에 `</chat>` 같은 태그를 넣어도 요청 구조를 흉내 낼 수 없습니다. (텍스트 내보내기 파일 자체의 가짜 줄은 위 '알려진 한계' 참고)
- 요청에는 지금 시각·내보낸 시각·마지막 메시지 이후 시간이 들어가, '내일' 같은 말과 답이 늦었는지를 모델이 판단할 수 있습니다.
- 접근성 API 로 입력창에 직접 넣는 기능은 대화방을 열어 읽음 처리를 일으킬 수 있어 넣지 않았습니다. 추가한다면 `output.py` 안에서, 명시적으로 켰을 때만, 전송 키는 누르지 않는 방식으로 만듭니다.
