# 하루 스피킹

영어로 **또렷하게(clear), 조리 있게(articulate)** 말하는 연습을 매일 10분씩 하게 해 주는 웹 앱입니다.
Articulate·Speeko·Orai·ELSA 같은 스피킹 코치 앱의 핵심 루틴(입 풀기, 발음 드릴, 섀도잉, 60초 즉흥 말하기, 말하기 분석, 연속 기록)을
한국어 화자에 맞춰 설치 없이 브라우저에서 쓸 수 있게 만들었습니다.

## 하루 세션 (기본 10분)

| 단계 | 하는 일 | 채점 |
| --- | --- | --- |
| **입 풀기** | 입술·혀·턱·호흡 워밍업, 타이머 안내 | — |
| **발음 드릴** | 한국어 화자가 헷갈리는 소리(R/L, F/P, V/B, TH, 장단모음…) 최소 대립쌍: 듣고 고르기 3 → 단어 말하기 6 → 문장 말하기 | 음성 인식이 정답 단어/짝 단어 중 무엇으로 들었는지 + 원어민 → 내 발음 이어 듣기 |
| **리듬·강세** | 단어 강세, 약모음, 연음, 축약(wanna), 문장 강세, 혀 꼬기 스피드 기록 | 단어 인식 + 원어민/내 녹음 비교(강세는 귀로 확인) |
| **섀도잉** | 원어민 음성(속도 조절)을 듣고 지문 따라 읽기. 읽는 동안 인식된 단어가 초록색으로 채워짐 | 단어 정확도, WPM, 놓친 단어 |
| **Daily 60** | 매일 바뀌는 질문 + 말하기 틀(PREP, STAR 등) + 15초 생각 → 60초 즉흥 답변 | 점수(분량·속도·막힘·어휘 다양성·또렷함), 코치 피드백, 받아쓰기, 녹음. 45초 미만이면 ‘미완료’ |
| **표현 업그레이드** | “very good” 같은 밋밋한 문장을 정확한 표현으로 바꿔 말하기 | 핵심 표현을 쓰고 밋밋한 말은 뺐는지 |

5분(발음 + Daily 60) / 15분(+ 읽은 글 30초 요약) 길이도 고를 수 있습니다.

### 처음 설정 (3분)

목표 시간 → 마이크 확인 → **발음 진단 8단어**(틀린 소리가 집중 연습 소리가 됨) → **첫 녹음**(매주 같은 글을 다시 읽어 비교) → 매일 알림.

### 점수에 대해

브라우저 음성 인식은 발음을 음소 단위로 채점하지 못합니다. 그래서 이 앱은 “인식기가 정답 단어로 알아들었는가”를 기준으로 하고,
인식기가 um·uh를 빼고 적는 한계, 강세·억양은 측정하지 못한다는 점을 화면에 그대로 밝힙니다. 강세·리듬은 원어민 → 내 녹음 비교로 귀로 확인합니다.

## 꾸준히 하게 만드는 장치

- **연속 기록**과 이번 주 도장, 15주 달력. 말하기 연습을 하나라도 하면 그날이 이어집니다(입 풀기만으로는 안 됨). 바쁜 날엔 Daily 60만 해도 됩니다.
- **연속 보호권**: 7일 연속마다 1개(최대 2개), 빠진 날만큼 자동으로 사용. 3·7·14·30·100일 달성 알림.
- **주간 체크**: 첫날 읽은 글을 매주 다시 녹음해 정확도·속도·목소리를 비교. **이번 주 vs 지난주** 요약.
- **복습**: 틀린 단어와 표현이 1 → 3 → 7 → 14 → 30일 간격으로 다시 나옵니다.
- **내 목소리 기록**: Daily 60 녹음과 받아쓰기를 쌓아 첫 녹음과 오늘을 비교해 들을 수 있습니다.
- **추이 그래프**: 점수, 말하기 속도, 분당 군더더기.
- **약점 맞춤**: 정확도 75% 미만인 소리는 더 자주, 섀도잉 난이도는 정확도에 따라 자동 조정.
- **매일 알림**: 휴대폰 캘린더에 매일 반복 일정(.ics)을 추가.

## 실행

빌드 없는 정적 사이트입니다. 마이크와 음성 인식을 쓰려면 `https` 또는 `localhost`에서 열어야 합니다.

```bash
cd speaking && python3 -m http.server 8000   # http://localhost:8000
```

- **Android·PC: Chrome**, **iPhone: Safari**에서 자동 채점이 됩니다(Web Speech API).
  Firefox 등 음성 인식이 없는 브라우저는 녹음 → 다시 듣기 → 자가 평가로 진행합니다.
- GitHub Pages로 배포하면 휴대폰에서 “홈 화면에 추가”해 앱처럼 쓸 수 있습니다.
- 기록과 녹음은 그 기기 브라우저(localStorage, IndexedDB)에만 저장됩니다. 설정의 백업 코드로 다른 기기에 옮길 수 있습니다.
