매일 자동으로 바꾸기

아래 주소는 매일 0시(한국 시간)에 그날 단어 이미지로 바뀝니다.

아이폰 설정 방법 (단축어)
  1. 단축어 앱 → 자동화 → + → 특정 시간 → 매일, 원하는 시각(예: 오전 6:00) → 즉시 실행.
  2. 동작 URL을 추가하고 위 주소를 붙여 넣기.
  3. 동작 URL의 콘텐츠 가져오기 추가.
  4. 동작 배경화면 설정(Set Wallpaper) 추가 → 잠금 화면 선택, 미리 보기 표시는 끄기.
  5. 이 페이지는 Safari 공유 버튼 → 홈 화면에 추가. 단어 뜻이 궁금하면 이 아이콘을 누르세요.
  6. iOS 18 이상이면 잠금 화면을 길게 눌러 사용자화 → 아래쪽 버튼(손전등·카메라 자리)을 단축어로 바꾸고, ‘URL 열기’로 이 페이지를 여는 단축어를 지정하면 잠금 화면에서 바로 뜻을 볼 수 있어요.
안드로이드 설정 방법
  1. MacroDroid나 Tasker 같은 자동화 앱을 설치.
  2. 트리거: 매일 원하는 시각.
  3. 동작: HTTP 요청으로 위 주소의 이미지를 파일로 저장 → 배경화면 설정에서 그 파일을 잠금 화면(또는 둘 다)에 지정.
  4. Chrome 메뉴 → 홈 화면에 추가(앱 설치)로 이 페이지를 앱처럼 두고, 뜻이 궁금하면 누르세요.
