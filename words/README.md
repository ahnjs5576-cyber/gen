# 오늘의 영단어

매일 다른 영단어 1~5개를 휴대폰 **배경화면**에 띄웁니다. 배경화면에는 영단어만 나오고,
앱(이 폴더의 웹 페이지)에서 단어를 누르면 **한글 뜻 · 품사 · 예문 · 예문 해석 · 발음**을 보여 줍니다.

- 단어 398개. 하루 5개 기준 79일 동안 같은 단어가 다시 나오지 않고, 그 뒤엔 순서를 새로 섞습니다. 이웃한 날끼리도 겹치지 않습니다.
- 단어 수를 1~3개로 줄이면 그날 5개 세트의 앞부분만 씁니다(앱 화면과 배경화면 이미지가 항상 같음).
- 날짜는 휴대폰의 현재 날짜(앱), 한국 시간(자동 생성 이미지) 기준입니다.

## 왜 앱이 따로 있나요

휴대폰 배경화면은 그림일 뿐이라 아이폰·안드로이드 모두 **배경화면 자체를 눌러 반응하게 할 수는 없습니다.**
그래서 배경화면과 똑같이 생긴 화면을 앱으로 만들었습니다. 홈 화면 아이콘(또는 아이폰 잠금 화면 버튼)을 누르면
배경화면과 같은 화면이 열리고, 거기서 단어를 누르면 뜻과 예문이 나옵니다.

## 설치

### 1. 배포 (한 번만)

1. 이 브랜치를 저장소의 **기본 브랜치**에 합칩니다(또는 이 브랜치를 기본 브랜치로 지정).
   매일 도는 예약 실행은 기본 브랜치에서만 동작합니다.
2. GitHub 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. **Actions** 탭에서 *Pages* 워크플로를 한 번 실행(Run workflow)하거나 기본 브랜치에 push 합니다.

그러면 아래 주소가 생깁니다(`<아이디>/<저장소>`는 본인 것으로).

| 무엇 | 주소 |
| --- | --- |
| 앱 | `https://<아이디>.github.io/<저장소>/words/` |
| 오늘 배경화면 (단어 N개) | `https://<아이디>.github.io/<저장소>/words/wall/N/today.jpg` |
| 날짜별 배경화면 | `https://<아이디>.github.io/<저장소>/words/wall/N/2026-11-25.jpg` |

워크플로가 매일 한국 시간 0시 5분에 오늘 이미지를 새로 만들고, 앞으로 30일치 날짜별 이미지도 함께 올립니다.
이미지 크기는 1290×2796(최신 아이폰 기준)이며 다른 휴대폰에서도 화면에 맞게 잘려 들어갑니다.

> GitHub는 저장소에 60일 동안 아무 활동이 없으면 예약 실행을 멈춥니다. 그때는 Actions 탭에서 다시 켜 주세요.

### 2. 아이폰 — 단축어로 매일 자동 변경

1. **단축어** 앱 → **자동화** → **+** → **특정 시간** → 매일, 원하는 시각(예: 오전 6:00) → **즉시 실행**.
2. 동작 **URL** → `…/words/wall/3/today.jpg` (3 자리에 원하는 단어 수 1~5).
3. 동작 **URL의 콘텐츠 가져오기**.
4. 동작 **배경화면 설정**(Set Wallpaper) → **잠금 화면** 선택, **미리 보기 표시** 끄기.
5. Safari에서 앱 주소를 열고 공유 → **홈 화면에 추가**.
6. (iOS 18 이상) 잠금 화면을 길게 눌러 **사용자화** → 아래쪽 손전등·카메라 버튼 자리에 **단축어**를 넣고,
   ‘URL 열기’로 앱 주소를 여는 단축어를 지정하면 잠금 화면에서 바로 뜻을 볼 수 있습니다.

### 3. 안드로이드

1. **MacroDroid**나 **Tasker** 같은 자동화 앱에서 매일 원하는 시각에
   `…/words/wall/3/today.jpg`를 파일로 받은 뒤(HTTP 요청) **배경화면 설정** 동작으로 지정합니다.
2. Chrome에서 앱 주소를 열고 메뉴 → **홈 화면에 추가**(앱 설치).

### 자동화 없이 쓰기

앱의 설정(톱니바퀴) → **오늘 배경화면 이미지 저장**을 누르면 지금 휴대폰 화면 크기에 맞는 이미지를 만들어 줍니다.
사진 앱에서 배경화면으로 지정하면 됩니다.

## 파일

```
words/index.html, style.css, app.js   앱 화면
words/core.js                          날짜 → 단어 배정, 배경화면 그리기 (앱과 이미지 생성이 함께 씀)
words/words.js                         단어 목록 [단어, 품사, 뜻, 예문, 해석]
words/wallpaper.html                   이미지 생성용 페이지 (미리보기: wallpaper.html?n=3&date=2026-11-25)
words/sw.js                            오프라인 캐시
scripts/words-validate.mjs             단어 목록 검사 (형식, 중복, 예문 속 단어, 날짜별 겹침)
scripts/words-wallpapers.mjs           배경화면 JPG 생성 (Playwright)
scripts/words-smoke.mjs                브라우저 스모크 테스트
.github/workflows/pages.yml            매일 이미지 생성 + GitHub Pages 배포
```

## 단어 추가·수정

`words/words.js` 배열에 `[단어, 품사, 뜻, 예문, 해석]`을 추가하고 검사합니다. 품사는 `n` `v` `adj` `adv` `conj`.
예문에는 그 단어(또는 변화형)가 들어 있어야 앱에서 강조 표시됩니다.
목록이 바뀌면 날짜별 배정이 새로 섞입니다.

```bash
node scripts/words-validate.mjs
node scripts/words-smoke.mjs
node scripts/words-wallpapers.mjs --days 3   # words/wall/ 에 미리 만들어 보기 (git에는 안 올라감)
```
