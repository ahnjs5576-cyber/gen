# 月への路面電車 — 달까지 가는 노면전차 (80초)

1990년대 OVA 셀 애니메이션 느낌의 80초 단편. **`moon-tram.html` 파일 하나**를 브라우저로 열면 됩니다.
그림, 움직임, 소리를 모두 코드로 직접 그립니다(외부 이미지·음원·라이브러리 없음).

- 열면 배경을 그리는 데 몇 초 걸리고, 그다음 화면을 클릭하면 재생됩니다(소리를 켜 주세요).
- 스페이스: 일시정지 · R: 처음부터 · F: 전체화면 · `moon-tram.html?t=40` 처럼 특정 초부터 재생

## 구성 (샷)
| 시간 | 장면 |
| --- | --- |
| 0–9s | 비 오는 밤, 지선 끝의 낮은 와이드. 깜빡이는 가로등, 물웅덩이 반사 |
| 9–13.5s | 승강 발판 아래 고양이 인서트 |
| 13.5–15.6s | 번개 컷(네거티브 실루엣 4프레임) → 헤드램프가 켜진 정면 회화풍 정지 컷 |
| 15.6–18s | 고양이가 놀라 도망(앤티시페이션, 스미어 프레임) |
| 18–25s | 팬터그래프 틸트업, 죽은 가선을 긁으며 불꽃 |
| 25–30.5s | 실내: 전등이 하나씩 켜지고 손잡이가 흔들림 |
| 30.5–34s | 행선지 롤러가 돌다가 초승달 칸에서 멈춤 |
| 34–40.5s | 바퀴 클로즈업: 모터 신음, 스프링 위 흔들림, 녹 조각, 담쟁이가 찢겨 나감 |
| 40.5–49s | 끊긴 선로 끝에서 빛의 선로가 빗방울로 한 칸씩 짜여 구름 틈의 보름달까지 |
| 49–54s | 바퀴 옆 트래킹: 무겁게 출발해 가속, 땅이 떨어져 나감 |
| 54–55.6s | 이륙 순간 회화풍 정지 컷 |
| 55.6–65s | 마을 위로 휘어 오르는 빛의 선로를 따라 긴 팬업, 종소리, 불꽃 꼬리 |
| 65–69.5s | 구름이 빛나며 갈라지고 전차가 그 안으로 |
| 69.5–80s | 거리 높이의 마지막 와이드: 웅덩이에 비친 하늘, 빛의 궤적이 별의 줄로, 고양이가 나와 올려다봄 |

## 기법 메모
- 셀: 가변 압력 잉크 리본, 색 트레이스선(조명 쪽은 주황/시안), 2단 하드 섀도 + 에어브러시 하이라이트, 셀 층의 미세한 색 분리
- 배경: 노이즈 기반 구름 + 붓질 텍스처(포스터컬러 느낌), 건물·지붕은 모두 시드별로 다르게 생성, 간판은 읽을 수 없는 붓 글자
- 타이밍: 24fps 기준, 작화는 2·3프레임 단위로 바뀌고(캐시로 재사용), 키 포즈는 손으로 정한 값으로 유지
- 필름: 할레이션, 프레임마다 바뀌는 약한 그레인, 게이트 위브, 비네트, 드문 먼지
- 소리: WebAudio 합성(비, 천둥, 금속 마찰음, 아크, 릴레이, 래칫, 모터, 종, FM 첼레스타, 스트링 패드·리드)

## 소스
`src/*.js`를 이어 붙여 `moon-tram.html`을 만듭니다.
```bash
node tools/build.mjs                       # moon-tram.html 생성 (문법 검사 포함)
node tools/snap.mjs out 4 13.6 47.5        # 지정한 초의 프레임을 PNG로 저장 (Playwright 필요)
node tools/perf.mjs                        # 프레임당 렌더 시간 측정
```
